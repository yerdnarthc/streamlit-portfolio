# Font assets

- `JetBrainsMonoNerdFont-Regular.ttf` is sourced from the [Nerd Fonts JetBrains Mono build](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/JetBrainsMono/Ligatures). Its accompanying license is `JetBrainsMonoNerdFont-OFL.txt`.
- `Geist-Bold.woff2` is sourced from the [Geist font project](https://github.com/vercel/geist-font).

These files are self-hosted so the deployed portfolio does not rely on fonts installed on a visitor's device.
